Two Sum: 필요한 짝을 HashMap에서 찾는다

완전탐색은 모든 쌍을 직접 확인한다. HashMap 풀이는 현재 값 cur의 짝 need = target - cur가 이전에 나왔는지만 확인한다.

손추적 시뮬레이터

nums = [2, 7, 11, 15], target = 9

핵심 코드

HashMap<Integer, Integer> map = new HashMap<>();

for (int i = 0; i < nums.length; i++) {
    int cur = nums[i];
    int need = target - cur;

    if (map.containsKey(need)) {
        return new int[] { map.get(need), i };
    }

    map.put(cur, i);
}

순서는 “need 확인 → 없으면 cur 저장”이다. 그래야 자기 자신을 두 번 쓰지 않는다.

완전탐색과 HashMap 비교

방식생각시간공간
이중 for문모든 j를 뒤져서 짝 찾기O(N²)O(1)
HashMap내 짝이 이전에 나왔는지 바로 확인O(N)O(N)
