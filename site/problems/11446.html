사탕 가방: mid는 가방 개수 후보

사탕 [5, 6, 7], 가방 하나당 필요한 사탕 수 M = 3. 아래 슬라이더로 “가방 X개 만들 수 있나?”를 직접 확인한다.

후보 가방 수: 5개

candies[i] / mid = i번 사탕을 mid개 가방에 똑같이 나누면 가방 하나에 몇 개 넣을 수 있는가.

이분 탐색 방향

if (canMake(mid)) {
    answer = mid;
    left = mid + 1;
} else {
    right = mid - 1;
}

이 문제는 가능한 최대 가방 개수를 찾는다. 가능하면 더 큰 가방 수를 보러 오른쪽으로 간다.

오늘 헷갈렸던 지점 정리

헷갈린 점정리
3 3 / 5 6 7의 의미사탕 종류 3개, 가방 하나당 3개 필요, 각 사탕 보유량은 5/6/7개
mid가 뭔지배열 인덱스가 아니라 가방 개수 후보
왜 나누는지mid개 가방을 같은 구성으로 만들려면 각 사탕을 mid등분해야 하기 때문
최대/최소 방향최대값은 true일 때 left = mid + 1, 최소값은 true일 때 right = mid - 1
