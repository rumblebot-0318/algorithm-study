포인터는 “손가락”이야 ☝️

연결 리스트에서 포인터는 숫자를 복사하는 게 아니라, 다음 노드를 가리키는 손가락이야. 두 줄을 차례대로 합치며 손가락이 어떻게 움직이는지 직접 눌러 보자.

오늘의 패턴
두 리스트 + tail
list1 / p1list2 / p2합친 결과 / tail
list1p1은 1을 가리켜요
list2p2는 1을 가리켜요
dummy → 합친 결과tail은 dummy를 가리켜요

팁: 한 번에 이해하려 하지 말고, 버튼을 누를 때마다 p1, p2, tail이 어디를 가리키는지 보자.

지금 하는 일

제일 중요한 약속
작은 값을 결과 뒤에 붙인 다음에는 tail = tail.next로 tail도 한 칸 이동한다.

포인터 패턴 지도

코드와 화면 연결하기

ListNode dummy = new ListNode(-1);ListNode tail = dummy;while (p1 != null && p2 != null) {  if (p1.val <= p2.val) tail.next = p1;  else                  tail.next = p2;  tail = tail.next;  // 꼬리도 앞으로!}tail.next = (p1 != null) ? p1 : p2;return dummy.next;
