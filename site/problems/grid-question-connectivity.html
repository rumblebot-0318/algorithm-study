Brute Force · BFS

문자 격자 ? 채우기: 모든 조합을 만들고 연결성을 검사한다

?마다 a / b / c를 하나 고른 뒤, 완성된 격자에서 존재하는 각 문자가 하나의 상하좌우 연결 그룹인지 BFS로 확인한다.

결정 단위

? 하나 → a, b, c 중 하나 선택

?가 Q개면 후보는 3Q개다. DFS는 현재 위치 idx에 문자를 하나 넣고 다음 ?로 내려간다.

for (char letter : letters) {
    combinations[idx] = letter;
    makeCombinations(idx + 1);
}

리프(idx == questions)에서만 조합을 격자에 적용하고 BFS 판정을 한다.

aa? 손추적

세 조합 모두 유효하다. 그래서 이 예제의 답은 3이다.

리프에서 하는 일: 조합 적용 → 문자별 BFS

// 원본은 다음 조합에서도 재사용하므로 deep copy
for (int y = 0; y < height; y++) {
    curTmp[y] = mapToCharArray[y].clone();
}

// ? 좌표에 현재 조합 적용
for (int i = 0; i < questionsNodes.size(); i++) {
    Node node = questionsNodes.get(i);
    curTmp[node.y][node.x] = combinations[i];
}

int sum = 0;
for (char letter : letters) {
    Node start = getPosition(letter, curTmp);
    if (start != null) sum += getCount(start, curTmp);
}
if (sum == totalSize) setCount++;

판정 불변식: 한 문자에서 처음 찾은 칸으로 BFS를 하면 그 문자와 연결된 덩어리 하나만 방문한다. 어떤 문자가 둘 이상으로 끊기면 방문 합이 전체 칸 수보다 작아진다.

복잡도와 주의점

항목내용
시간O(3Q × N) — Q개의 물음표 조합마다 N칸 격자를 검사
공간O(N + Q) — 복사 격자, 방문 배열, 현재 조합
방문 처리큐에 넣는 순간 visited[nextY][nextX] = true로 바꿔 중복 삽입을 막는다.
빈 문자어떤 문자가 아예 없으면 BFS를 건너뛴다. 이 풀이에서는 그 자체를 실패로 세지 않는다.

현재 코드의 조합 생성은 ?가 하나 이상 있다는 전제다. 물음표가 없을 수도 있다면 DFS 시작 전에 원본 격자를 바로 검사하는 분기가 필요하다.
