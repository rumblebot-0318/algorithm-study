게임 맵 최단거리: 큐에 넣을 때 방문 처리

현재 칸에서 상·하·좌·우로 한 칸씩 이동한다. 길은 1, 벽은 0이다.

PriorityQueue 탐색 흐름

방문 처리 위치

if (!visited[nextY][nextX]
        && maps[nextY][nextX] == 1) {
    visited[nextY][nextX] = true;
    queue.add(new Node(
        nextY, nextX, cur.dist + 1));
}

방문 처리를 큐에 넣기 전에 한다. 같은 칸을 다른 경로가 발견해도 이미 true라서 중복 삽입되지 않는다.

시작점도 queue.add(...) 직후 visited[0][0] = true가 필요하다.
