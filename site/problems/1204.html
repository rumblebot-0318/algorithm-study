최빈수 구하기: 점수를 배열 인덱스로 센다

점수 범위가 0~100으로 작기 때문에 count[score]++ 방식으로 빈도를 기록한다.

카운팅 배열 시각화

아래 점수 버튼을 누르면 빈도가 증가한다.

핵심 포인트

for (int score = 0; score <= 100; score++) {
    if (count[score] >= maxCount) {
        maxCount = count[score];
        answer = score;
    }
}

동점이면 큰 점수를 출력해야 하므로 작은 점수부터 보면서 >=일 때 갱신한다.
