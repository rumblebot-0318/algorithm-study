# SWEA 1954. 달팽이 숫자

## 문제 유형

- 난이도: D2
- 유형: 구현, 2차원 배열, 방향 전환
- 핵심: 한 칸씩 이동하다가 막히면 방향을 바꾼다.

## 접근

`N x N` 배열을 만들고 숫자 `1`부터 `N * N`까지 채운다.

방향은 다음 순서로 반복한다.

```text
오른쪽 -> 아래 -> 왼쪽 -> 위
```

현재 방향으로 다음 칸을 계산했을 때,

1. 배열 범위 안이고
2. 아직 방문하지 않은 칸이면

그 칸으로 이동해서 숫자를 채운다.

반대로 다음 칸이 범위 밖이거나 이미 숫자가 들어있으면 방향만 바꾼다.

## 핵심 코드

```java
while (num <= N * N) {
    int ny = y + dir[dirIdx][0];
    int nx = x + dir[dirIdx][1];

    if (canMove(ny, nx)) {
        y = ny;
        x = nx;
        map[y][x] = num++;
    } else {
        dirIdx = (dirIdx + 1) % 4;
    }
}
```

## 이동 가능 여부

```java
static boolean canMove(int y, int x) {
    return y >= 0 && y < N
        && x >= 0 && x < N
        && map[y][x] == 0;
}
```

## 헷갈렸던 점

처음에는 `while` 안에서 `for (int i = 0; i < N; i++)`처럼 일정 횟수만큼 이동하려고 생각할 수 있다.

하지만 이 문제는 다음 규칙 하나로 보는 게 더 쉽다.

```text
다음 칸으로 갈 수 있으면 이동하고,
못 가면 방향을 바꾼다.
```

그래서 한 번의 반복에서는 한 칸 이동 여부만 판단하면 된다.

## 시간복잡도

모든 칸을 한 번씩 채우므로:

```text
O(N^2)
```
