# SWEA 2001. 파리 퇴치

## 문제 유형

- 난이도: D2
- 유형: 2차원 배열, 완전탐색
- 핵심: 가능한 모든 시작 좌표에서 `M x M` 영역의 합을 구하고 최댓값을 찾는다.

## 접근

`N x N` 배열에서 `M x M` 크기의 파리채를 놓을 수 있는 모든 위치를 확인한다.

파리채가 배열 밖으로 나가면 안 되므로 시작 좌표는 `0`부터 `N - M`까지만 가능하다.

예를 들어 `N = 5`, `M = 2`라면 마지막 시작 좌표는 `3`이다.

```text
x = 0 -> [0, 1] 가능
x = 1 -> [1, 2] 가능
x = 2 -> [2, 3] 가능
x = 3 -> [3, 4] 가능
x = 4 -> [4, 5] 불가능
```

그래서 반복문은 다음처럼 작성한다.

```java
for (int y = 0; y <= N - M; y++) {
    for (int x = 0; x <= N - M; x++) {
        max = Math.max(max, checkMap(y, x));
    }
}
```

## 내 스타일 풀이

안쪽 `M x M` 합산은 함수로 분리한다.

```java
static int checkMap(int y, int x) {
    int sum = 0;

    for (int i = y; i < y + M; i++) {
        for (int j = x; j < x + M; j++) {
            sum += map[i][j];
        }
    }

    return sum;
}
```

이렇게 보면 전체 코드를 다음처럼 읽을 수 있다.

```text
모든 시작 좌표를 돈다.
각 좌표에서 M x M 합을 구한다.
최댓값을 갱신한다.
```

## 3중 포문이 아니라 4중 반복

이 문제의 기본 완전탐색은 실제로는 4중 반복이다.

```text
시작 y 반복
  시작 x 반복
    파리채 내부 y 반복
      파리채 내부 x 반복
```

다만 안쪽 2중 반복을 `checkMap()` 함수로 빼면 이해하기 더 쉽다.

## 주의할 점

처음에는 다음처럼 모든 좌표를 시작점으로 볼 수도 있다.

```java
for (int y = 0; y < N; y++) {
    for (int x = 0; x < N; x++) {
        max = Math.max(max, checkMap(y, x));
    }
}
```

그리고 `checkMap()` 안에서 범위 체크를 할 수도 있다.

```java
if (i < N && j < N) {
    sum += map[i][j];
}
```

하지만 이건 문제를 다음처럼 해석한 코드가 된다.

```text
파리채가 밖으로 나가도 배열 안쪽에 걸친 부분만 잡는다.
```

SWEA 2001은 `N x N` 배열 안에서 `M x M` 영역을 고르는 문제이므로, 파리채가 온전히 들어가는 시작 좌표만 보는 것이 정석이다.

## 시간복잡도

가능한 시작 좌표는 대략 `N^2`개이고, 각 위치마다 `M^2`칸을 더한다.

```text
O(N^2 * M^2)
```

SWEA 2001 제한에서는 완전탐색으로 충분하다.
