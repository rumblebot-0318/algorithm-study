SWEA 2001

파리 퇴치: 모든 시작 좌표를 확인한다

파리채가 배열 밖으로 나가지 않는 시작점만 보고, 각 위치의 M×M 합을 계산한다.

시작 좌표 선택

핵심 구조

for (int y = 0; y <= N - M; y++) {
    for (int x = 0; x <= N - M; x++) {
        max = Math.max(max, checkMap(y, x));
    }
}

안쪽 M×M 합은 checkMap(y, x)로 분리하면 “모든 시작 좌표를 돈다 → 함수로 계산한다 → 최댓값 갱신한다”로 읽힌다.
