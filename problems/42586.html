기능개발: 앞 기능을 기다려 같이 배포한다

완료일이 빠르더라도 앞 기능보다 먼저 배포할 수 없다. 배포 기준일과 현재 묶음의 크기만 관리한다.

한 단계씩 보기

기억할 규칙 하나

if (left <= currentDays) {
    count++;
} else {
    ans.add(count);
    currentDays = left;
    count = 1;
}

left <= currentDays면 현재 기능은 먼저 끝났더라도 앞 기능을 기다린다. 따라서 같은 배포 묶음에 넣는다.

완료일은 (100 - progress + speed - 1) / speed로 올림 계산한다.
