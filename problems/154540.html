무인도 여행 + DFS의 되돌리기

섬의 합은 한 번 방문한 칸을 영구 표시한다. 반대로 최장 경로 DFS는 다른 길도 시험해야 하므로, 재귀에서 돌아올 때 방문을 되돌린다.

최장 경로 DFS: 한 경로를 끝까지 갔다가 되돌리기

🟨 현재 경로🟩 탐색을 끝낸 분기🟪 다음 선택지

원복을 결정하는 질문

“다른 경로에서도 이 칸을 다시 써봐야 하는가?”

문제 목표방문 처리
무인도 섬 합한 번 합산하면 끝 → 원복 없음
BFS 최단거리먼저 도착한 경로가 최단 → 원복 없음
DFS 최장 단순 경로다른 갈림길도 비교 → 원복 필요
visited[y][x] = true;
dfs(nextY, nextX, length + 1);
visited[y][x] = false; // backtracking

DFS = 무조건 원복이 아니다. 현재 경로 전용 방문 배열일 때만 원복한다.
